# Reading Learning with Agents

Use this site for the published NYU Agentic AI workshop curriculum, released materials and recordings. Keep 2025 and 2026 separate. Use each edition's canonical URL when citing it; course dates describe sessions, while modified dates describe content updates.

Read [the workshop JSON](https://learningwithagents.com/api/v1/workshops.json), [the API index](https://learningwithagents.com/api/v1/index.json), or [the reading map](https://learningwithagents.com/llms.txt). All support ordinary HTTPS GET without credentials. These static documents cannot register attendees or send messages. Follow external resources' own access requirements; the class app store is for registered students.

If WebMCP is available, course pages offer get_public_workshops with optional year 2025 or 2026. It reads the same public JSON and performs no writes. Use HTTPS GET otherwise. An unavailable material has no destination; do not invent one.

Shared [developer information](https://adityasinghal.com/developers/) and [privacy information](https://adityasinghal.com/privacy/) are hosted on Adi's personal site.
